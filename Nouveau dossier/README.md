# ASHFALL: LAST SURVIVOR

Prototype jouable du **Milestone 1** : environnement en tuiles, caméra qui suit le personnage, collisions, déplacement, sprint et HUD de survie.

## Lancer dans VS Code

1. Ouvrir le dossier `Nouveau dossier` dans VS Code.
2. Installer l'extension **Live Server** si elle n'est pas déjà présente.
3. Clic droit sur `index.html`, puis **Open with Live Server**.
4. Utiliser `WASD` ou les flèches pour se déplacer, `Shift` pour sprinter, `E` pour interagir et `Échap` pour mettre en pause.

Le jeu utilise un module JavaScript (`src/main.js`) : un serveur local est recommandé plutôt qu'une ouverture directe avec `file://`.

## État actuel

Le personnage est un placeholder pixel-art procédural, afin de pouvoir remplacer facilement son rendu par la future sprite sheet sans changer les systèmes de jeu. Les ennemis, l'inventaire complet et le combat sont prévus pour les milestones suivants.
